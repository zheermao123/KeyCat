# ACCEPTANCE_CRITERIA — 验收与发布门禁

**状态：** ACCEPTED（1.0 范围；随阶段推进细化）
**来源：** PRD §10 + 执行计划门禁；决策依据见 DECISIONS.md

## 1. KeyCat 1.0 最终验收（实机 Windows 环境）

### 输入法验收
- [ ] 安装后能够在 Windows 输入法列表中找到 KeyCat 输入法。
- [ ] 能够在记事本、浏览器、Office 等常见应用输入中文。
- [ ] 全拼输入、声母简拼输入正常（双拼不在验收范围，D-A06）。
- [ ] 候选词选择和中英文切换正常。
- [ ] 用户词频能够保存。
- [ ] 自定义词库能够备份和恢复。
- [ ] 断网后仍然能够正常输入。
- [ ] KeyCat 主界面关闭后输入法仍然工作。
- [ ] 更新软件后用户配置不会丢失。

### 个性化猫咪验收
- [ ] 可以导入真实猫咪照片（1–5 张，D-A02）。
- [ ] 能够生成 2D 卡通角色（8GB 显存单张 ≤60s 目标线，D-B02）。
- [ ] 角色具有透明背景。
- [ ] 角色主要外观特征与原照片相符（用户确认制，D-A01 风格基准 + 特征相符）。
- [ ] 角色可以保存并重新加载。
- [ ] 能够替换 KeyCat 默认猫咪（多角色保存，同一时间一个活动角色，D-A05）。
- [ ] 至少支持待机、睡觉和观察动作。
- [ ] AI 生成失败时可以保留原角色（D-B04）。

### 整体产品验收
- [ ] AI 生成不能明显影响输入法响应（进程隔离，D-T05）。
- [ ] 桌面猫退出不影响输入法。
- [ ] 输入法异常不影响桌面猫。
- [ ] 安装、升级、卸载和修复流程正常。
- [ ] 用户照片、角色和输入法个人数据受到保护（PRD §7）。

## 2. Phase 0 完成门禁

**项目审计**：项目状态和架构有完整记录；复用与重构范围明确；桌面猫与输入法边界明确。

**输入法技术**：Weasel 构建或部署可行；librime 基础输入可用；Rime Ice 配置成功加载；全拼和声母简拼通过原型验证；KeyCat 品牌定制范围明确；候选窗口主题可行；上游独立更新入口可控；用户数据路径明确。

**安装与更新**：安装权限方案完成实测；TSF 注册方式明确；更新和回滚方案明确；用户数据保护方案明确。

**许可证**：代码、配置、词库和模型分别审查；再分发条件明确；所有阻塞性授权问题有结论。

**测试**：原版输入法基线完成；测试语料固定；测试环境可重复。

**角色并行准备**：多图融合原型完成；4 张候选图方案经过验证；视觉基准候选已建立；角色 Schema 初步完成。

> 许可证和输入法集成门禁未通过，不得进入 Phase 1 正式开发。

## 3. Phase 1 发布门禁

**功能**：全拼、声母简拼、候选词、数字选词、空格选词、中英文切换、中文标点、动态词频、用户词库保存、离线输入、KeyCat 候选窗口主题全部正常。

**独立运行**：关闭主窗口 / 退出桌面猫 / AI Worker 不运行时输入法仍正常；输入法重启后用户数据仍存在。

**安装与更新**：干净系统安装、覆盖升级、修复安装、卸载、用户数据保留、更新失败恢复、UAC 取消处理全部通过。

**性能**：完成原版对比；延迟回归 ≤ 基线 +10%；首选命中率未下降；内存差异有记录；长时间运行测试通过。

**许可证与发布**：第三方许可证清单完整；发布包含必要版权声明；组件版本可追溯；构建可重复；安装包完整性验证通过；高优先级缺陷清零。

## 4. 阶段就绪门禁（DoR）

- **Phase 1**：许可证/再分发方案明确；D-A06/D-A08 已定；P0-00 构建环境清单产出。
- **Phase 3**：视觉基准冻结；动画规格（含帧尺寸、朝向翻转）冻结；Character Bundle Schema 冻结；多图融合方案冻结。
- **Phase 5**：安装原型实测完成（D-A09）。
